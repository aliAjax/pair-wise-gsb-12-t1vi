# 山路冷链 · 派车交接台

- 行业：物流（山路冷链）
- 技术栈：Vue3、Vite、TypeScript、Pinia、Element Plus
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

针对"换车、司机休息断在半路"的场景：派车前把温区、载重、保养、休息缺口写明，
途中改派先交回剩余线路、原占用立即释放，确认后新车继续承运。

## 分层维护

| 层 | 位置 | 内容 |
| --- | --- | --- |
| 资料 | `src/data/seed.ts` + 各资料 Tab | 订单（线路/送达窗口/货温/重量）、车辆（核载/温区/保养时点）、司机（班次/连续驾驶时长） |
| 判断 | `src/domain/rules.ts` | 温区、载重、保养、休息、撞班的缺口判定，纯函数，可单测 |
| 留档 | `src/stores/dispatch.ts` | 派车单与交接记录的状态流转，localStorage 持久化，重开续看 |
| 界面 | `src/App.vue` | 调度台（待派区/在途组合/交接确认）+ 资料维护 + 交接留档 |

## 流程

1. **待派区**：选车选司机后实时判定；同车或同一司机撞班、温区/载重/保养/休息不够，
   订单留在待派区并写明缺口。
2. **派车 → 发车**：发车后原组合锁定，车辆与司机进入占用。
3. **途中改派**：填已跑里程与原因，系统按剩余线路校验新组合；
   提交即交回剩余线路、原占用立刻释放并回写原车保养里程与原司机驾驶时长。
4. **确认交接**：确认时再校验一次新车新司机，通过后新车继续承运。
5. **送达完成**：释放组合，回写车辆保养剩余里程与司机连续驾驶时长。
